HOW I
BUILT IT

Hogg Squash is a squash game for the Hogg Middle School Razorbacks that plays in any web browser. It’s my GT Capstone project.

My guiding question: How can AI tools help one student research, design and build a complete video game?

I research, plan, play-test and make the decisions; Claude Code writes the code. The game is built in small steps. Each step is a short work session that ends with a commit: a saved change on GitHub. Between some steps I play-test the game and decide what to fix next.

This log is my process record. It reads every commit straight from GitHub, so it’s always up to date, and old versions stay playable so you can see how the game grew.

All the code is open on GitHub. See how it works, or fork it and make your own version →

THE TOOLS

  • Claude

    AI help: researching the 1992 arcade game, planning the build, and answering questions along the way.

  • Claude Code

    The AI coding assistant that wrote the game and this website, one session at a time.

  • Cloudflare

    Registers the roninray.com domain and hosts the game and this site.

  • GitHub

    Stores the code and every change to it. This page reads its log from there.

  • SpriteCook

    AI pixel-art generator for the player sprites and their animations.

  • Aseprite

    Pixel-art editor for cleaning up the sprites: colors, sizes and exporting the animations.
