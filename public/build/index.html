HOW I
BUILT IT

Hogg Squash is built in small steps. Each step is a short work session that ends with a commit: a saved change on GitHub. Between some steps I stop to play-test the game and decide what to fix next.

This page reads those commits straight from GitHub, so it is always up to date. Old versions stay playable, so you can see how the game grew.

All the code is open on GitHub. See how it works, or fork it and make your own version →

THE LOG

  1. R RESEARCH

    Researching the 1992 arcade game

    Oct 18, 2026 · done with Claude, before any code

    1. Picked Gaelco's Squash (1992) as the model and read up on it: first to 9 points, HARD and SOFT shots, 8 players and a tournament.

      Oct 18 · Research the original game

    2. Found out what the original runs on: a 1992 arcade board with a Motorola 68000 processor, running code written for that chip alone.

      Oct 18 · The original's hardware

    3. Pulled the graphics and sound clips out of the game's ROM to study, for reference only.

      Oct 18 · ROM graphics and sound extracted

    4. Ran the real game in an arcade emulator with a robot player to confirm the rules and measure the ball's speed.

      Oct 18 · MAME test runs

    5. Decompiled the game's code to find the exact ball physics, shots and computer opponent.

      Oct 18 · Ghidra decompile

      Technical notes
      - Ghidra 12.1.3 on the 68000 program ROM
- Turned the arcade's machine code back into readable code
- Found the ball physics, shot tables, CPU "ghost ball" predictor and difficulty tables

    6. Chose JavaScript, the language every web browser runs, so Hogg Squash is a complete rewrite that plays on any computer, tablet or phone with nothing to install.

      Oct 18 · Platform: browser and JavaScript

    7. Rebuilt the ball physics in JavaScript and checked it against about 30,000 frames of the real game, with zero error.

      Oct 18 · Physics core and tests

      Technical notes
      - 16.16 fixed-point maths like the original, so every browser gets identical results
- 458 ball flights, 29,634 frames: zero error
- 244 / 244 shot choices identical
- Moved into the game repo in adb444c

    8. Wrote design notes on what to keep, what to change and what to leave out.

      Oct 18 · Design notes
